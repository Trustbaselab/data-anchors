# Key findings:
#
# 1. REACH Annex XVII Entry 50 is the real EU compliance gate for rCB,
#    NOT food-contact regulation (EU 10/2011 applies to food-contact plastics
#    only, not tyres). Three rCB pathways:
#    - Synthetic turf granules: sum of 8 PAHs <= 20 mg/kg (from 2022-08-10)
#    - Tyres: indirect via extender oils + Bay protons <= 0.35%
#    - Consumer articles: each PAH <= 1 mg/kg; toys <= 0.5 mg/kg
#
# 2. ISCC PLUS officially classifies rCB as a CO-PRODUCT (not residue).
#    Source: ISCC PLUS 202-5 Waste and Residues v1.1, section 2.3.
#    Only tyres NOT fit for reuse/recycling count as ISCC waste.
#    Point of Origin = tyre sorting operator, not the pyrolysis plant.
#
# 3. Carbon black price structure (6 observations, Jan-Oct 2026):

#    N220 - N330 = 1000 CNY/t (constant, 6/6)
#    N660 = N330 (constant, 6/6)
#    All grades rose 3220 CNY/t Jan->Oct 2026 (+43% to +51%)
#    Carbon black price movement is a PURE LEVEL SHIFT, grade spreads are
#    structurally constant. Therefore rCB's absolute customer savings grow
#    with native carbon black prices.
